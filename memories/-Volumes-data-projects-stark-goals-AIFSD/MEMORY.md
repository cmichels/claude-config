# AIFSD Goal - Standards, Practices & Tech Radar Adoption

## Project Purpose
Professional development goal: Proactively contribute to AIFSD standards, practices,
and Tech Radar adoption through documentation, showcases, and knowledge sharing.

## Key Deliverables (4 each)
1. Documented showcases: AI review pipeline, worktree workflow, debugging with AI, CLAUDE.md workshop
2. Reusable artifacts: prompt library, Go debug playbook, PR checklist, dev env setup guide
3. Tech Radar recommendations: Claude Code PR reviews (Adopt), worktrees (Adopt), MCP (Trial), TBD (Assess)
4. Feedback & impact tracking: surveys, Confluence analytics, retro mentions, adoption signals
