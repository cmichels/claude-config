# Security Policy

## Reporting a Vulnerability

If you discover a security issue, do not open a public issue.

Please report privately via GitHub Security Advisories for this repository.
Include:

- clear reproduction steps
- affected files or commands
- impact assessment
- suggested remediation if available

## Scope

Security issues include (but are not limited to):

- credential or token exposure
- unsafe command execution paths
- privilege escalation via config or automation
- sensitive data leakage in tracked artifacts

## Response Expectations

- Initial triage target: within 3 business days
- Confirmed issues get prioritized remediation and patch guidance
- Public disclosure should wait until a fix or mitigation is available
